# Fase 8a — Internacionalização (PT/EN) — Plano de Implementação

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Suporte PT/EN completo na interface de configuração e nas
mensagens de erro da placa 2D, com cada idioma vivendo no seu próprio
arquivo de texto simples (`res/lang/pt.txt`/`res/lang/en.txt`),
editável sem tocar em código C, e com auto-detecção pelo idioma do
Windows.

**Architecture:** Um novo módulo `src/i18n.c/.h` define um `enum StrId`
(130 chaves) e `i18n_str(StrId)`/`i18n_init(int lang)`. Os dois
arquivos de idioma são embutidos no `.scr` via o `build/tools/embed.c`
já existente. Cada aba do diálogo ganha uma função `X_apply_i18n(HWND)`
que aplica `i18n_str()` a todos os controles daquela aba — chamada uma
vez no `WM_INITDIALOG` de cada aba, e de novo (pra todas as abas) quando
o novo dropdown "Idioma" (aba Desempenho) muda de valor.

**Tech Stack:** C11, WinAPI (`SetDlgItemTextW`, `CB_RESETCONTENT`,
`GetUserDefaultUILanguage`), reaproveita `build/tools/embed.c`.

## Global Constraints

- ~40 controles estáticos do `.rc` hoje usam `-1` como ID (sem
  identificador próprio) — cada um ganha um ID novo dentro do bloco
  numérico já reservado pra sua aba em `resource.h`, pra poder ser
  alvo de `SetDlgItemTextW` individualmente.
- Nenhuma tradução compartilha chave entre controles de contextos
  diferentes, mesmo quando o texto atual coincide (ex.: "Desligado"
  aparece em Bevel/Streaks/MSAA — 3 chaves distintas). Só os botões de
  ação genéricos (Escolher.../Limpar/Escolher cor...) e o rótulo
  "Arquivo:"/placeholder "(nenhum)" reaproveitados literalmente no
  mesmo papel usam a mesma chave — e esses já têm IDs próprios, não
  precisam de ID novo.
- O `.rc` mantém o texto em português tal como está — é o fallback de
  compilação caso o i18n falhe ao carregar.
- Build: `mingw32-make -f build/Makefile debug` (ou `release`) da raiz,
  com w64devkit no PATH. Testes: `mingw32-make -f build/Makefile test`.
  Sempre `mingw32-make -f build/Makefile clean` antes de builds depois
  de editar um `.h` ou trocar debug↔release.

/* decodifica \n e \\ dentro do valor; escreve em buf (UTF-16, ja
   convertido de UTF-8 pelo chamador) */
static void unescape_inplace(wchar_t *s)
{
    wchar_t *r = s, *w = s;
    while (*r) {
        if (r[0] == L'\\' && r[1] == L'n') { *w++ = L'\n'; r += 2; }
        else if (r[0] == L'\\' && r[1] == L'\\') { *w++ = L'\\'; r += 2; }
        else *w++ = *r++;
    }
    *w = 0;
}

{
    memset(have, 0, sizeof(int) * STR_COUNT);

    int wlen = MultiByteToWideChar(CP_UTF8, 0, utf8, -1, NULL, 0);
    wchar_t *wide = (wchar_t *)malloc((size_t)wlen * sizeof(wchar_t));
    if (!wide) return;
    MultiByteToWideChar(CP_UTF8, 0, utf8, -1, wide, wlen);

    wchar_t *line = wide;
    while (*line) {
        wchar_t *nl = wcschr(line, L'\n');
        if (nl) *nl = 0;
        wchar_t *cr = wcschr(line, L'\r');
        if (cr) *cr = 0;

        wchar_t *p = line;
        while (*p == L' ' || *p == L'\t') ++p;
        if (*p && *p != L'#') {
            wchar_t *eq = wcschr(p, L'=');
            if (eq) {
                *eq = 0;
                wchar_t *key = p;
                wchar_t *val = eq + 1;

                char keyA[128];
                WideCharToMultiByte(CP_UTF8, 0, key, -1, keyA, (int)sizeof keyA, NULL, NULL);
                for (int i = 0; i < STR_COUNT; ++i) {
                    if (strcmp(keyA, KEY_NAMES[i]) == 0) {
                        wchar_t *dup = (wchar_t *)malloc((wcslen(val) + 1) * sizeof(wchar_t));
                        if (dup) {
                            wcscpy(dup, val);
                            unescape_inplace(dup);
                            free(out[i]);
                            out[i] = dup;
                            have[i] = 1;
                        }
                        break;
                    }
                }
            }
        }

        if (!nl) break;
        line = nl + 1;
    }
    free(wide);
}

void i18n_init(int language)
{
    if (g_pt[0] == NULL && g_en[0] == NULL) {
        /* primeira chamada: parseia os dois arquivos embutidos uma vez so' */
        parse_lang_file((const char *)EMBED_pt_txt, g_pt, g_have[0]);
        parse_lang_file((const char *)EMBED_en_txt, g_en, g_have[1]);
        for (int i = 0; i < STR_COUNT; ++i) {
            if (!g_have[0][i]) log_errorf("i18n: chave ausente em pt.txt: %s", KEY_NAMES[i]);
            if (!g_have[1][i]) log_errorf("i18n: chave ausente em en.txt: %s", KEY_NAMES[i]);
        }
    }

    int lang = language;
    if (lang == 0) {   /* auto */
        lang = (PRIMARYLANGID(GetUserDefaultUILanguage()) == LANG_PORTUGUESE) ? 1 : 2;
    }
    g_active_lang = (lang == 2) ? 1 : 0;
}

const wchar_t *i18n_str(StrId id)
{
    if (id < 0 || id >= STR_COUNT) return L"";
    if (g_active_lang == 1 && g_have[1][id]) return g_en[id];
    if (g_have[0][id]) return g_pt[id];
    if (g_have[1][id]) return g_en[id];

    static wchar_t fallback[160];
    swprintf(fallback, 160, L"[%hs]", KEY_NAMES[id]);
    return fallback;
}
